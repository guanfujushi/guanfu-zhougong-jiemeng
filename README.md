## 怎么用

1. 把本仓库整个目录放进你的 skills 目录，例如 `~/.skills/guanfu-zhougong-jiemeng/`；
2. 在 AI 助手对话中按 SKILL.md 里描述的触发方式调用；
3. 零依赖、纯知识方法论包——不联网、不调付费接口。
